## 示例2：并行智能体部署

### 阶段1：公司事实底座 - 并行启动4个智能体

**实施**：

```
我现在为阶段1：公司事实底座并行启动4个研究智能体...

[Task 智能体1A]
研究贵州茅台的核心业务和产品。
重点：产品组合、业务板块、收入驱动。
来源：年报、公司网站、投资者说明会。

[Task 智能体1B]
研究贵州茅台的收入和利润构成。
重点：分部拆解、各产品线盈利能力、收入趋势。
来源：分部报告、财务报表、管理层讨论分析。

[Task 智能体1C]
研究贵州茅台的客户和价值链定位。
重点：客户群体、分销渠道、竞争地位。
来源：行业报告、公司披露、渠道分析。

[Task 智能体1D]
研究贵州茅台近期战略变化（过去3-5年）。
重点：i茅台APP、直销举措、定价策略演变。
来源：过去5年年报、新闻档案、新闻稿。

---

所有4个智能体现在并行运行。完成后我将收集他们的发现。
```

### 收集结果

智能体全部完成后（每个通常3-5分钟，但因并行化总计约5分钟）：

```
**阶段1智能体结果摘要**：

**智能体1A**（产品）：
- 核心产品：飞天茅台 - 高端白酒
- 系列产品：王子酒、迎宾酒等 - 中/低端
- 收入构成：飞天茅台约85%收入，系列约15%
- 品牌定位："国酒茅台" - 送礼和宴请的奢侈白酒

**智能体1B**（收入）：
- 2023年营收：1275亿元（+18.2% YoY）
- 毛利率：91.2%（稳定，高端定价）
- 飞天茅台利润率：约93%，系列利润率：约75%
- 净利润：747亿元（+18.3% YoY）

**智能体1C**（客户）：
- 主要客户：高收入个人、企业（送礼）、政府（公务宴请）
- 分销：约95%通过批发经销商，约5%直销（i茅台APP增长中）
- 客户集中度：无单一客户>5%
- 价值链：上游（粮食采购）→ 生产（专有发酵）→ 分销（批发）→ 终端客户

**智能体1D**（战略）：
- 2022年：推出i茅台APP（直接面向消费者）
- 2023年：直销增至5%（从<1%）
- 2021-2023年：多次提价（累计约10-15%）
- 战略：通过减少中间商获取更多利润

**共识**：所有智能体确认茅台是占主导地位的高端白酒生产商，正在扩展直销。
**无矛盾**：发现在各智能体之间一致。
```

## 示例3：阶段报告生成

### 阶段1报告: `01_Business_Foundation.md`

```markdown
# 阶段1: 公司事实底座

## 执行摘要

贵州茅台是中国领先的高端白酒生产商，在超高端细分市场占据主导地位。公司的商业模式建立在强大的品牌护城河、专有生产技术和源于稀缺性的定价权之上。近期战略举措聚焦于通过i茅台APP平台扩展直销渠道以获取经销商利润。

**关键事实**：
- 2023年营收：1275亿元（+18.2% YoY）
- 核心产品：飞天茅台（85%收入）
- 毛利率：91.2%
- 主要客户：高收入个人、企业、政府
- 分销：95%批发、5%直销（增长中）

## 1.1 核心业务和产品

**商业模式**：生产和销售高端白酒（中国白酒），主要通过批发经销商向终端客户销售，用于送礼、宴请和个人消费。

**产品组合**：

| 产品 | 价格区间 | 收入% | 利润率 | 增速 |
|------|---------|-------|-------|------|
| 飞天茅台 | ¥2500-3000/瓶 | ~85% | ~93% | +15% |
| 系列酒 | ¥200-800/瓶 | ~15% | ~75% | +10% |

**关键洞察**：
- 飞天茅台是利润奶牛，拥有卓越的93%毛利率
- 系列产品提供较低但仍健康的利润率
- 稀缺性是内在的（发酵时间限制产能）
- 定价权：2021-2023年多次提价成功

[... 以下内容按原始示例继续展开 ...]

## 关键要点

1. **强大品牌护城河**：飞天茅台在中国高端白酒市场拥有不可撼动的品牌地位
2. **卓越利润率**：91%毛利率证明了定价权和稀缺性
3. **战略转型**：正在向直销转型以获取经销商利润（30%+提升）
4. **供给约束**：产能受地理位置和发酵时间限制
5. **定价权**：多次提价成功实施且需求强劲

## 红旗识别

1. **监管风险**：政府曾针对奢侈品"过度定价"
2. **供给约束**：有限的产能扩张可能制约增长
3. **估值风险**：高估值倍数（P/E >30）留给错误的空间很小
4. **竞争**：五粮液等高端白酒生产商正在缩小差距

## 来源

**A级来源**（最权威）：
- 贵州茅台股份有限公司2023年年度报告 [贵州茅台, 2024年4月, https://www.cninfo.com.cn]
```

## 示例4：质量保证

### 引用验证

完成一个阶段后，调用 `citation-validator` 技能：

```
请验证 RESEARCH/STOCK_600519_Kweichow_Moutai/01_Business_Foundation.md 中的引用

检查：
1. 完整性：每个声明有作者、日期、标题、URL
2. 格式一致性：所有引用遵循相同格式
3. 来源质量：所有来源已评级（A-E级）
4. 缺失引用：是否有无来源的声明
5. 矛盾声明：是否有冲突信息

提供报告包括：
- 引用质量摘要
- 缺失或有问题的引用列表
- 修正建议
```

## 示例5：最终综合

### 执行摘要: `00_Executive_Summary.md`

```markdown
# 执行摘要

## 信号评级

🟡🟡🟡 **持有 / 合理估值**

**依据**: 贵州茅台是一家卓越的企业，拥有主导性品牌护城河和定价权。但当前估值（P/E约32倍）留给安全边际的空间有限。我们建议持有现有仓位，但对新投资等待更好的入场点（10-15%回调）。

## 投资论点

**一句话**: 茅台是中国无可争议的高端白酒领导者，拥有不可撼动的品牌护城河和90%+毛利率，但以充分估值交易且存在监管和执行风险。

## 关键指标汇总

| 指标 | 值 | 背景 |
|------|-----|------|
| 市值 | ¥2.8万亿（约$3,900亿） | A股最大消费品公司 |
| TTM营收 | ¥1,275亿 | +18.2% YoY |
| TTM净利润 | ¥747亿 | +18.3% YoY，净利率58.6% |
| P/E (TTM) | 32倍 | 高于5年均值28倍 |
| P/B | 13倍 | 处于历史均值 |
| ROE (TTM) | 31% | 行业领先，稳定 |
| 股息率 | 1.2% | 派息率约38% |

## 考虑的前3个理由

1. **不可撼动的品牌护城河**：茅台的"国酒"地位和文化意义创造了无法复制的竞争优势。品牌拥有800年历史，深嵌中国送礼和庆祝文化。

2. **卓越的经济特征**：91%毛利率和53%净利率位居全球消费品前列。公司拥有定价权（持续提价）和稀缺性（有限产能）。

3. **强劲的现金创造**：OCF/NI比率>1.0，零负债，大量FCF支持分红增长和潜在回购。5年营收CAGR 15.8%，ROE 30%+展示卓越资本效率。

## 回避的前3个理由

1. **充分估值**：P/E 32倍交易，高于5年均值28倍，2.5倍于全球奢侈品同行。安全边际有限。当前价格隐含15%长期增长（在品类成熟的背景下偏乐观）。

2. **监管风险**：政府多次针对"过度定价"和"过度消费"。2021年监管机构迫使茅台取消一次提价。未来干预可能影响定价权。

3. **竞争加剧**：五粮液等高端白酒生产商在品牌和营销上大力投入，正在缩小差距。茅台在超高端细分市场的份额从65%下降至58%（5年）。

## 估值评估

**场景分析**：

| 场景 | 假设 | 隐含价值 (¥/股) | 上行/下行 |
|------|------|----------------|---------|
| 乐观 | 2030年前18%增长，3%终端 | ¥2,800 | +35% |
| 基准 | 2030年前15%增长，3%终端 | ¥2,050 | 0%（当前） |
| 悲观 | 2030年前10%增长，2%终端 | ¥1,400 | -32% |

**行动**: 🟡🟡🟡 持有 / 等待更好入场点
```
