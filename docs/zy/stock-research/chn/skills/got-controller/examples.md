# GoT控制器技能 - 示例

## 示例1：AI医疗研究的GoT图构建

### 初始问题
"AI在临床诊断中的应用：当前状态、挑战和机遇"

### GoT操作序列

**步骤1：Generate - 初始展开**

```
Generate("AI临床诊断", 5) →
  节点A："市场规模和增长"
  节点B："技术准确率和能力"
  节点C："供应商格局和竞争"
  节点D："实施挑战和成本"
  节点E："监管环境和伦理"
```

**步骤2：Score - 初始评估**

部署5个研究智能体并行研究后：

```
Score(A) = 8.5（强 - 多个来源一致）
Score(B) = 9.2（强 - 同行评审来源）
Score(C) = 7.8（良好 - 有Gartner数据）
Score(D) = 8.0（良好 - 多个案例研究）
Score(E) = 5.5（弱 - 来源少、快速变化的领域）
```

**步骤3：Refine - 改进低分节点**

```
Refine(E) →
  - 添加FDA最新法规数据
  - 添加EU AI Act影响分析
  - 补充伦理讨论的学术来源
  Score(E_refined) = 7.8 ✅
```

**步骤4：Generate - 深度展开高价值节点**

```
Generate(B, 3) →
  节点B1："各专科AI准确率对比"
  节点B2："实验室 vs 真实世界表现差距"
  节点B3："技术成熟度评估"
```

**步骤5：Aggregate - 综合**

```
Aggregate(A, B, C, D, E_refined) →
  "AI在临床诊断中的应用：综合报告"
  评分：9.2/10
```

### 最终图状态

```
            [AI临床诊断]
           /    |    |    \     \
         [A]  [B]  [C]  [D]  [E→E']
        8.5  9.2  7.8  8.0   7.8
              / | \
           [B1][B2][B3]
           8.5 9.0 8.2
                    \
              [最终综合报告] ← Aggregate
                   9.2
```

## 示例2：投资研究的混合策略

### 场景
研究贵州茅台（600519），用户关注：价值投资、长期持有、重点关注护城河和估值

### GoT策略：混合（广度扫描 + 重点深入）

**步骤1：广度扫描 - 8个阶段**

```
Generate("贵州茅台投资研究", 8) →
  阶段1："公司事实底座"  → 标准覆盖
  阶段2："行业周期分析"  → 标准覆盖
  阶段3："业务拆解"      → 🔥 深度（用户关注护城河）
  阶段4："财务质量"      → 标准覆盖
  阶段5："治理分析"      → 🔥 深度（用户关注）
  阶段6："市场情绪"      → 标准覆盖
  阶段7："估值与护城河"  → 🔥 深度（用户最关注）
  阶段8："最终综合"      → 最终聚合
```

**步骤2：资源分配**

```
深度阶段（3, 5, 7）：每阶段4个智能体 = 12个智能体
标准阶段（1, 2, 4, 6）：每阶段3个智能体 = 12个智能体
综合（8）：1个综合器
总计：25个智能体

→ 相比均匀分配（每阶段4个 = 32个智能体），
   减少了7个智能体同时提高了重点领域质量
```

**步骤3：执行和评分**

```
完成后评分：
阶段1：7.5（标准）
阶段2：7.2（标准）
阶段3：9.0（深度）✅
阶段4：7.8（标准）
阶段5：8.5（深度）✅
阶段6：6.8（标准）⚠️ 需精炼
阶段7：9.2（深度）✅

平均：7.9/10

操作：Refine(阶段6) → 补充市场情绪数据
```

**步骤4：最终聚合**

```
Aggregate(阶段1-7) → 执行摘要 + 综合报告
最终评分：8.8/10 ✅ 发布级
```

## 示例3：处理矛盾的GoT操作

### 场景
两个智能体对茅台定价权的评估矛盾：

```
智能体A发现："茅台拥有不可撼动的定价权，
  多次成功提价（2021-2023累计提价10-15%）"
  来源：公司年报、管理层评论

智能体B发现："茅台定价权受到政府限制，
  2021年被迫取消一次提价"
  来源：监管新闻、政策分析
```

### GoT解决方案

**步骤1：识别矛盾类型** → D类（范围差异）

**步骤2：Generate - 补充调查**
```
Generate("茅台定价权争议", 2) →
  节点X："历史提价时间线和结果"
  节点Y："政府干预的频率和影响"
```

**步骤3：Aggregate（含矛盾解决）**
```
Aggregate(A, B, X, Y) →
综合结论："茅台拥有强大但非绝对的定价权。
公司在2021-2023年成功实施了约10-15%的累计提价
（贵州茅台年报, 2022-2024），但2021年在政府压力下
取消了一次提价（财新, 2021年8月）。
定价权评估：85/100（强，但存在监管约束）"
```

## 示例4：GoT决策流程图

### 何时使用哪个操作

```
收到研究任务
     │
     ▼
[初始问题是否清晰？]
     │
  否 ─→ 调用 question-refiner
     │
  是 ─→ Generate(主题, 5-7)
          │
          ▼
     [部署智能体研究]
          │
          ▼
     Score(所有节点)
          │
      ┌───┴───┐
      ▼       ▼
  评分≥7   评分<7
      │       │
      │    Refine(节点)
      │       │
      │    重新Score
      │       │
      ├───────┘
      ▼
  [需要更多深度？]
      │
   是 ─→ Generate(节点, 3-4)
      │         │
      │    返回Score步骤
      │
   否 ─→ Aggregate(所有完成节点)
              │
              ▼
        [综合报告]
              │
              ▼
         Score(报告)
              │
         ≥8 ─→ ✅ 交付
              │
         <8 ─→ Refine(报告)
```

## 关键GoT原则

1. **Generate时要有目的**：每个新节点都应有明确的研究焦点
2. **Score后再行动**：不要在评分前就聚合或生成
3. **Refine而非重做**：低分节点优先精炼，不是重新生成
4. **策略性聚合**：确保聚合的输入节点质量足够
5. **平衡广度和深度**：用有限资源最大化研究质量
