## 示例1：价值投资 - A股蓝筹

### 用户初始请求

```
用户：我想知道贵州茅台 600519 值不值得投资
```

### 问题细化器的回复

```
我可以帮您对贵州茅台进行投资研究，但我不能直接告诉您"值不值得买"或给
出投资建议。不过，我可以帮您系统性地研究这家公司，帮您做出自己的判断。

为了给您提供最合适的研究，我需要了解一些信息：

**1. 您的投资风格是什么？**
   A. 价值投资 - 寻找被低估的优质资产，关注安全边际
   B. 成长投资 - 关注高成长性，愿意为成长付出溢价
   C. 红利投资 - 关注稳定分红和现金流
   D. 其他

**2. 您的持有周期？**
   A. 短期（6个月以内）
   B. 中期（6-18个月）
   C. 长期（1-3年以上）

**3. 您最关心哪些方面？（选2-3个）**
   - 生意质量：护城河、定价权、商业模式
   - 财务质量：现金流、盈利质量
   - 行业态势：行业周期、竞争格局
   - 公司治理：管理层、资本配置
   - 估值：是否便宜、安全边际
   - 催化剂：近期催化因素

**4. 您的风险偏好？**
   - 保守：避免高负债、风险资产
   - 平衡：可接受适度风险
   - 激进：可承受高波动

请告诉我您的选择，我会据此生成针对性的研究计划。
```

### 用户回复

```
用户：
1. 价值投资，关注安全边际
2. 长期持有，3年以上
3. 最关心：生意质量、公司治理、估值
4. 风险偏好：保守
```

```markdown

  - 安全边际评估

  - 国际奢侈品对比（LVMH、Kering、Hermès）

  - 基准、乐观、悲观三种情景
  - 保守假设：WACC、终端增长率（2-3%）
  - 敏感性分析（WACC × 增长率）
```

## 示例2：成长投资 - 美股科技股

### 用户初始请求

```
用户：Should I invest in Nvidia (NVDA)?
```

### 问题细化器的回复

```
我无法告诉您是否应该投资英伟达，但我可以帮助您对该公司进行全面的投资研究。

为了创建量身定制的研究计划，我需要了解您的背景：

**1. 您对科技股的投资方法是什么？**
   A. 成长投资 - 关注长期趋势和高增长潜力
   B. GARP（合理价格的成长） - 平衡增长与估值
   C. 动量投资 - 关注价格动量和趋势

**2. 您计划持有多长时间？**
   A. 短期（不到1年）
   B. 中期（1-3年）
   C. 长期（3年以上）

**3. 什么对您最重要？**
   - AI/数据中心增长故事
   - GPU竞争定位
   - 估值（是否高估？）
   - 财务和利润率
   - 管理层/愿景

**4. 风险容忍度？**
   A. 保守（避免波动性大的股票）
   B. 平衡（可容忍一定波动）
   C. 激进（适应高波动）

请告诉我您的偏好，以便我据此定制研究。
```

### 用户回复

```
用户：
- 成长投资，相信AI长期论点
- 长期持有（5年以上）
- 重点：竞争定位、AI增长潜力、管理层执行力
- 风险容忍度：激进（我知道科技股波动大）
```

| 投资风格 | 关键重点 | 估值方法 | 风险考量 |

| **价值** | 内在价值、安全边际、护城河 | P/B、EV/EBITDA、DCF（保守） | 过度支付、价值陷阱、护城河侵蚀 |
| **成长** | TAM、竞争定位、增长可持续性 | PEG、DCF（激进）、用户价值模型 | 估值压缩、增长放缓、竞争 |
| **困境反转** | 流动性、偿付能力、重组、催化剂 | 清算价值、期权价值、恢复情景 | 全部损失、二元结果、时间线不确定 |
| **红利** | 收益率可持续性、派息率、FCF创造 | DDM、收益率 vs 替代品、FCF覆盖 | 股息削减、派息率过高、监管风险 |
