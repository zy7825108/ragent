# 问题细化器技能 - 示例

## 示例1：AI医疗研究 - 完整问答流程

### 用户输入
"帮我研究一下AI在医疗领域的应用"

### 步骤1：提出澄清性问题

```
好的！在开始研究之前，我需要了解一些信息以定制研究方向：

1. **主题聚焦**：在AI医疗中，你最关注哪个方面？
   - AI辅助诊断（影像、病理）
   - AI药物发现和研发
   - AI医院运营管理
   - AI远程医疗和数字健康

2. **输出格式**：你需要什么类型的报告？
   - 综合研究报告
   - 商业分析报告
   - 简明摘要

3. **范围**：
   - 地理范围：全球 / 中国 / 美国 / 其他？
   - 时间范围：过去几年到现在？需要未来预测吗？

4. **受众**：谁会阅读这份报告？

5. **深度**：你需要多详细的分析？

6. **特殊要求**：有没有特别想了解的供应商、技术或应用场景？
```

### 步骤2：用户回复

```
用户：
1. 主要关注AI辅助诊断，特别是影像诊断
2. 综合研究报告
3. 全球范围，2020-2024，需要未来3年预测
4. 医院管理层和IT负责人
5. 标准分析
6. 想对比几个主要AI影像诊断供应商
```

### 步骤3：生成结构化提示词

```markdown
### TASK
分析2020-2024年AI在医学影像诊断中的全球应用现状，评估其临床价值、
技术成熟度和实施挑战，比较主要供应商，并为医院管理层提供采用策略建议。

### CONTEXT / BACKGROUND
AI辅助影像诊断是医疗AI中最成熟、应用最广泛的领域，在放射学、
病理学等专科已展示出超越人类医生的准确率。随着技术成熟和成本降低，
越来越多的医院正在考虑部署AI影像系统。本研究旨在为医院管理层
提供全面的市场、技术和实施指南。

### SPECIFIC QUESTIONS
1. AI在放射学、病理学、心脏病学等专科的诊断准确率分别是多少？
   与人类医生相比有多大提升？
2. 实验室准确率和真实临床环境中的准确率差距有多大？主要原因是什么？
3. 全球AI影像诊断市场规模是多少？2024-2027年的增长预测是什么？
4. 主要AI影像诊断供应商（如IBM Watson、Google Health等）的市场份额、
   产品特点和竞争优势是什么？
5. 医院部署AI影像系统的典型成本、实施时间和关键成功因素是什么？
6. 监管环境（FDA、NMPA等）对AI影像产品的审批要求和趋势是什么？
7. 对于中国/全球三级医院，推荐的AI影像采用路径是什么？

### KEYWORDS
**主要关键词**：AI医学影像、AI辅助诊断、计算机辅助检测、深度学习影像分析
**同义词和变体**：人工智能放射学、机器学习病理、AI radiology、
  computer-aided diagnosis、deep learning medical imaging
**相关概念**：数字病理、PACS系统集成、医疗AI监管、FDA AI/ML审批

### CONSTRAINTS
- **时间范围**：2020-2024年（现状），2025-2027年（预测）
- **地理范围**：全球（重点关注美国、中国、欧洲市场）
- **来源类型**：优先同行评审研究（准确率数据），行业报告（市场数据），
  公司文件（供应商数据）
- **篇幅**：主报告15-20页，执行摘要2-3页
- **语言**：中文报告（英文来源保留原文引用）

### OUTPUT FORMAT
**执行摘要**：800-1000字，关键发现和建议
**主报告结构**：
1. 市场概览 - 规模、增长、细分（2-3页）
2. 技术评估 - 准确率对比、成熟度评估（3-4页）
3. 供应商对比 - 主要厂商分析和对比矩阵（3-4页）
4. 实施指南 - 成本、时间、成功因素（2-3页）
5. 监管环境 - 各市场审批要求（1-2页）
6. 建议和结论 - 采用路径和行动计划（2-3页）
**附录**：供应商对比表、参考文献

### FINAL INSTRUCTIONS
- 引用要求：每个数据点必须有引用（作者、日期、标题、URL）
- 来源质量：准确率数据使用A级来源（同行评审），市场数据使用B级来源
- 客观性：均衡呈现AI的优势和局限性
- 注意事项：区分实验室准确率和真实世界准确率
```

## 示例2：简单查询的处理

### 用户输入
"新能源汽车行业怎么样？"

### 步骤1：澄清

```
你想了解新能源汽车行业的哪些方面？让我帮你精确定位：

1. **聚焦方向**：
   - 行业投资价值分析
   - 技术发展趋势（电池、充电、自动驾驶）
   - 市场格局和竞争态势
   - 政策环境和补贴变化
   - 特定公司的研究

2. **地理范围**：中国 / 全球 / 特定市场？

3. **时间维度**：现状分析还是需要未来预测？

4. **用途**：投资决策 / 学术研究 / 商业规划 / 一般了解？

5. **深度**：快速概览（30分钟）还是深入分析（数小时）？
```

### 如果用户说"你决定"

```
好的，我为你设定以下默认值：

- 聚焦：中国新能源汽车行业的市场格局和投资价值[默认值]
- 地理：中国为主，对比全球[默认值]
- 时间：2022-2024年现状 + 2025-2027年预测[默认值]
- 用途：投资参考[默认值]
- 深度：标准分析[默认值]

如果这些设定不符合你的需求，请告诉我需要调整的地方。
否则我将基于以上设定生成结构化提示词。
```

## 质量对比

### ❌ 糟糕的结构化提示词

```
### TASK
研究AI

### SPECIFIC QUESTIONS
1. AI怎么样？
2. AI未来会怎样？

### CONSTRAINTS
- 无
```

**问题**：太模糊、不具体、没有约束

### ✅ 优秀的结构化提示词

```
### TASK
评估2023-2024年生成式AI（以GPT-4和Claude为代表）在企业知识管理
应用中的ROI、实施挑战和最佳实践，为500-2000人规模的中国科技企业
提供采用建议。

### SPECIFIC QUESTIONS
1. 企业部署生成式AI知识管理系统的平均ROI是多少？回收期多长？
2. 最常见的3个失败原因是什么？如何避免？
3. 成功案例中的共同特征是什么？（行业、规模、方法）
4. 数据安全和隐私合规（GDPR、中国数据安全法）如何处理？
5. 自建 vs 采购 vs 混合方案的成本对比是什么？

### CONSTRAINTS
- 时间范围：2023-2024年
- 地理范围：中国为主，对比美国市场
- 来源类型：咨询机构报告、案例研究、技术评测
- 篇幅：10-15页
```

**优点**：具体、有边界、可操作

## 关键原则总结

1. **永远先问再做** - 省去返工的时间
2. **具体胜过模糊** - "2023年全球市场规模" > "市场怎么样"
3. **约束定义质量** - 有边界的研究才是好研究
4. **默认值要明示** - 让用户知道你做了什么假设
5. **耐心是美德** - 多问一个问题胜过交付一个模糊的研究
