# 引用验证器技能 - 示例

## 示例1：验证AI医疗研究报告的引用

### 输入文档（片段）

```markdown
全球AI医疗市场在2023年达到224亿美元，预计到2030年以37.5%的
CAGR增长（Grand View Research, 2024）。诊断影像代表了最大的
细分市场，占总市场的32%。

AI诊断准确率在多个专科超过人类临床医生：
- 放射学：AI 94% vs 人类 88%（Smith et al., 2023）
- 病理学：AI 96% vs 人类 90%
- 心脏病学：AI 91% vs 人类 87%（Lee et al., 2023）

实施成本通常在50万至500万美元之间（KPMG, 2024），
实施时间线为6-18个月。
```

## 示例2：幻觉检测

### 输入声明

```markdown
根据McKinsey 2024年全球AI调查，73%的企业已在至少一个
业务功能中部署了AI（McKinsey, 2024）。
```

### 验证过程

**使用WebSearch验证**：
- 搜索："McKinsey 2024 global AI survey adoption rate"
- 发现：McKinsey 2024报告实际数据为"72%"，不是"73%"

**结果**：
- 幻觉类型：数据篡改（轻微）
- 严重性：🟡 中等
- 建议：将数字修正为72%

## 示例3：完整的验证报告

### 输入：贵州茅台研究报告片段

```markdown
贵州茅台2023年营收达到1275亿元，同比增长18.2%

在全球消费品公司中位列前列。飞天茅台的建议零售价
为1499元/瓶，但市场实际售价通常在2500-3000元。
```

| 3 | 毛利率91.2% | ❌ 无引用 | - | - | - |
| 4 | "全球前列" | ❌ 无引用 | - | - | - |
| 5 | 指导价1499元 | ❌ 无引用 | - | - | - |

## 关键原则

1. **宁严勿松**：标记所有可疑声明
2. **提供解决方案**：不仅指出问题，还建议修复方法
3. **区分严重性**：幻觉 > 缺失引用 > 不完整引用 > 格式问题
4. **使用工具验证**：不要仅靠记忆判断准确性
5. **客观公正**：评估来源质量，而非来源观点
