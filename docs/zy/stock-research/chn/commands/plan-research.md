# 研究规划

为给定的结构化研究提示词创建详细的研究执行计划。

## 结构化提示词

$ARGUMENTS

## 你的任务

使用 **research-executor** 技能（仅阶段2：检索规划）来：

1. **分解主要问题**：基于 SPECIFIC_QUESTIONS 分解为3-7个子主题

2. **生成搜索查询**：为每个子主题创建具体的搜索查询

3. **识别数据来源**：基于 CONSTRAINTS 选择适当的来源

4. **创建研究计划**：
   - 列出子主题及研究问题
   - 为每个子主题指定搜索查询
   - 识别目标来源（学术、行业、新闻等）
   - 定义多智能体部署策略
   - 估算时间线

5. **展示计划待批准**：展示计划并询问用户是否继续

## 输出格式

```markdown
## 研究计划

### 待研究的子主题：
1. **[子主题1名称]**
   - 研究问题：[具体问题]
   - 搜索查询：[查询1, 查询2, 查询3]
   - 目标来源：[来源类型]

2. **[子主题2名称]**
   - 研究问题：[具体问题]
   - 搜索查询：[查询1, 查询2, 查询3]
   - 目标来源：[来源类型]

...

### 多智能体部署策略：
- **总智能体数**：[数量]
- **智能体类型**：[网络研究、学术、验证]
- **预计时间线**：[估算]

### 输出结构：
[描述文件夹和文件结构]

准备好继续了吗？（是/否/需要修改）
```

现在创建研究计划。
