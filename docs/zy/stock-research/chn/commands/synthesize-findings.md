# 综合发现

将多个研究智能体的发现整合为连贯、结构良好的研究报告。

## 发现目录

$ARGUMENTS

## 你的任务

使用 **synthesizer** 技能来：

1. **审查和组织**：读取指定目录中的所有研究发现

2. **识别主题**：按共同主题和话题分组发现

3. **构建共识**：
   - 强共识：3个以上高质量来源支持的发现
   - 中等共识：2个来源支持的发现
   - 弱共识：仅来自1个来源的发现
   - 无共识：矛盾发现且无法解决

4. **解决矛盾**：
   - A类：数值差异
   - B类：因果声明
   - C类：时间变化
   - D类：范围差异

5. **创建结构化报告**：
   ```markdown
   # [研究主题]：综合报告

   ## 执行摘要
   ## 1. 引言
   ## 2. [主题1] - 共识发现
   ## 3. [主题2]
   ## 4. [存在矛盾的主题] - 解决方案
   ## 5. 整合分析
   ## 6. 空白和局限性
   ## 7. 结论和建议
   ## 参考文献
   ```

6. **维护引用**：在全文中保持所有来源归属

## 质量检查清单

- [ ] 所有重要发现已纳入
- [ ] 矛盾已确认并解决
- [ ] 共识与少数观点有清晰区分
- [ ] 引用已保留且准确
- [ ] 叙事连贯且逻辑合理
- [ ] 洞察具有可操作性
- [ ] 空白已确认

## 输出

将综合报告保存到研究目录中的 `full_report.md`。

现在开始综合。
