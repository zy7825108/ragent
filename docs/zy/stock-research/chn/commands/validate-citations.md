# 引用验证

验证研究文档中所有引用的准确性、完整性和质量。

## 文件路径

$ARGUMENTS

## 你的任务

使用 **citation-validator** 技能来：

### 步骤1：声明检测
识别文档中的所有事实声明：
- 统计数据和数字
- 日期和时间线
- 技术规格
- 市场数据
- 性能声明
- 引述和转述

### 步骤2：引用存在性检查
验证每个事实声明都有引用

### 步骤3：引用完整性检查
验证每个引用包含：
1. 作者/机构
2. 发布日期
3. 来源标题
4. URL/DOI
5. 页码（如适用）

### 步骤4：来源质量评估
使用A-E量表评级每个来源：
- **A**：同行评审、系统综述、随机对照试验
- **B**：队列研究、临床指南、知名分析师
- **C**：专家意见、案例报告、机制研究
- **D**：预印本、初步研究、博客
- **E**：轶事、理论性、推测性

### 步骤5：引用准确性验证
使用 WebSearch 或 WebFetch 验证来源实际支持所述声明

### 步骤6：幻觉检测
识别无支持来源或引用不正确的声明

### 步骤7：生成验证报告

```markdown
# 引用验证报告

## 执行摘要
- **分析的声明总数**：[数量]
- **有引用的声明**：[数量]（[百分比]%）
- **完整引用**：[数量]（[百分比]%）
- **准确引用**：[数量]（[百分比]%）
- **潜在幻觉**：[数量]
- **整体质量评分**：[评分]/10

## 严重问题（需立即处理）
[列出任何幻觉或严重准确性问题]

## 详细发现
[逐行或逐声明分析]

## 建议
[按优先级排列的修复列表]
```

## 输出

将验证报告保存到研究目录中的 `sources/citation_validation_report.md`。

现在开始引用验证。
