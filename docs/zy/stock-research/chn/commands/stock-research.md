## 研究工作流

本指令将执行以下步骤：

### 步骤1：问题细化（问题细化）

使用 **stock-question-refiner** 技能收集上下文并澄清研究需求。

**该技能将询问**：
1. **基本信息**：股票代码、公司名称、市场（A股/港股/美股）
2. **投资风格**：价值投资、成长投资、困境反转或红利投资
3. **持有周期**：短期（<6个月）、中期（6-18个月）或长期（1-3年以上）
4. **研究重点**：生意质量、财务、估值、治理等（选2-3个）
5. **研究深度**：快速扫描、标准尽调或深度分析
6. **特别关注**：任何需要调查的特定担忧或红旗

**等待用户回复**后再进入步骤2。

### 步骤2：研究执行计划（研究计划）

基于用户偏好创建详细的执行计划：
- 根据用户重点领域确定阶段优先级
- 设计多智能体部署策略（约28个智能体）
- 定义输出结构和文件组织
- 向用户展示计划待确认

### 步骤3：多智能体研究（多智能体研究）

为每个阶段部署多个**并行研究智能体**（使用Task工具）：

**阶段1**：公司事实底座（4个智能体）
- 产品和商业模式
- 收入和利润构成
- 客户和价值链
- 近期战略变化

**阶段2**：行业分析（4个智能体）
- 行业周期阶段
- 供需动态
- 竞争格局
- 政策和外部变量

**阶段3**：业务拆解（4个智能体）
- 业务板块深度分析
- 利润引擎和经济特征
- 客户和定价分析
- 子公司和非核心项目

**阶段4**：财务质量（4个智能体）
- 关键指标和趋势分析
- 现金流质量
- 异常筛查（红旗）
- 同行对比

**阶段5**：治理分析（4个智能体）
- 股权结构
- 管理层质量和激励
- 资本配置历史记录
- 股东回报和股份悬浮

**阶段6**：市场情绪（4个智能体）
- 多头案例研究
- 空头案例研究
- 关键争论点
- 验证节点

**阶段7**：估值与护城河（4个智能体）
- 竞争护城河评估
- 相对估值
- 绝对估值（DCF、反向DCF）
- 风险情景

**关键规则**：始终**并行**启动智能体（单条消息中多次Task工具调用），而非顺序启动。

### 步骤4：质量保证（质量保证）

**强制交叉验证**：
- 利润 vs 现金流（OCF/NI比率分析）
- 公司 vs 同行对比
- 空头案例分析（识别3-5个关键风险）

**引用验证**：
- 使用 **citation-validator** 技能验证所有声明都有引用
- 确保来源质量评级（A-E级）
- 检查缺失或有问题的引用

### 步骤5：最终综合（综合报告）

在以下目录中生成全面的投资尽调报告：

## 输出格式

### 执行摘要包含：

**信号灯评级**：
- 🟢🟢🟢 **强烈买入** - 显著安全边际、强护城河、估值有吸引力
- 🟡🟡🟡 **持有** - 合理估值或安全边际有限
- 🔴🔴 **回避** - 高估、基本面恶化或风险过大

**还包括**：
- 投资论点（一句话 + 详细阐述）
- 关键指标汇总表
- 考虑的前3个理由
- 回避的前3个理由
- 财务健康评分
- 估值评估（相对 + 绝对）
- 护城河评级（0-5）
- 监控清单（强化/退出条件）

### 每个阶段报告包含：

- 执行摘要（2-3段）
- 含子章节的详细发现
- 关键数据表格
- 来源质量评估（A-E评级）
- 矛盾和空白
- 关键要点（3-5个要点）

## 引用要求

**每个事实声明必须包含**：
1. 作者/机构名称
2. 发布日期（至少年份）
3. 来源标题
4. 直接URL/DOI
5. 页码（如适用）

**来源质量评级**（A-E级）：
- **A**：年报、监管文件、同行评审研究
- **B**：行业报告、知名分析师研究、公司演示
- **C**：新闻文章、专家评论
- **D**：预印本、初步研究、博客
- **E**：社交媒体、论坛（需用一手来源验证）

**引用格式示例**：
```markdown
根据2023年年报，贵州茅台营收同比增长18.2%至1275亿元，
其中茅台产品销量增长16.7%
[贵州茅台股份有限公司, 2024年年度报告, 2024年4月,
https://www.cninfo.com.cn/new/disclosure/detail?stockCode=600519&announcementId=122]
```

## 本系统能做什么

✅ **全面研究**：8阶段尽调，覆盖所有重要方面
✅ **多智能体并行执行**：约28个研究智能体同时工作
✅ **基于事实**：所有声明都经过来源验证和质量评级
✅ **均衡**：多头和空头案例均被呈现
✅ **结构化**：标准化输出便于浏览

## 本系统不做什么

❌ **不提供投资建议**：不给出买入/卖出/持有建议
❌ **不预测股价**：不预测未来股票价格
❌ **不做市场择时**：不识别入场/退出点
❌ **不提供交易策略**：不提供技术分析或交易信号

**信号灯评级（🟢🟢🟢 / 🟡🟡🟡 / 🔴🔴）**仅基于**基本面分析**（生意质量、财务健康、估值、护城河），**不是**投资建议。

## 预估时间

| 研究深度 | 时间 | 部署智能体数 |
|---------|------|-----------|
| 快速扫描 | 30-60分钟 | 约8-10个 |
| 标准尽调 | 2-4小时 | 约28个 |
| 深度分析 | 4-8小时 | 约40+个 |

**实际时间因以下因素而异**：
- 股票复杂度（业务板块数量、地理敞口）
- 数据可用性（A股有中文来源，美股数据更多）
- 研究深度优先级（越多优先阶段 = 越多时间）
