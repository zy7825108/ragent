## 1. 什么是 `/stock-research` 命令

### 1.1 命令简介

`/stock-research` 是一个**一键式股票投资尽调命令**,它能帮你:

- ✅ **自动执行完整的8阶段投资研究流程**
- ✅ **部署约28个并行研究智能体**,全方位分析公司
- ✅ **生成带信号评级的专业投资尽调报告**(🟢/🟡/🔴)
- ✅ **验证所有引用和数据准确性**,确保研究质量

**类比理解**: 就像你雇佣了一支28人的专业分析师团队,同时从不同角度研究一家公司,最后汇总成一份完整报告。

### 1.2 一句话总结

> **输入股票代码 → 回答几个问题 → 等待2-3小时 → 获得一份完整的投资尽调报告**

### 1.3 适用人群

| 人群 | 是否适合 | 说明 |
|------|---------|------|
| **价值投资者** | ⭐⭐⭐⭐⭐ 完美适合 | 重点关注护城河、估值、安全边际 |
| **成长投资者** | ⭐⭐⭐⭐⭐ 完美适合 | 重点关注成长性、竞争地位、TAM |
| **长期投资者** | ⭐⭐⭐⭐⭐ 完美适合 | 8阶段分析覆盖长期因素 |
| **短线交易者** | ⭐⭐ 不太适合 | 本框架不关注技术分析、价格预测 |
| **新手投资者** | ⭐⭐⭐⭐ 很适合 | 能快速学习专业研究方法 |

### 1.4 核心特点

**✅ 专业性**: 基于专业投资机构的尽调方法论

**✅ 全面性**: 8阶段覆盖投资决策的所有关键维度

**✅ 客观性**: 只基于事实和数据,不给投资建议

**✅ 高效性**: 并行智能体大幅缩短研究时间

**✅ 可追溯**: 每个结论都有引用来源(A-E质量评级)

## 3. 完整工作流程

### 3.1 第1步: 输入股票代码

**用户操作**:
```bash
/stock-research 600519      # A股 (贵州茅台)
/stock-research AAPL        # 美股 (苹果)
/stock-research 00700.HK    # 港股 (腾讯)
```

**系统响应**: 自动调用 `stock-question-refiner` 技能

---

### 3.2 第2步: 问题细化(交互式提问)

**系统会问4个关键问题**:

#### 问题1: 投资风格

```
**1. 您的投资风格是什么?**
   A. 价值投资 - 寻找被低估的优质资产,关注安全边际
   B. 成长投资 - 关注高成长性,愿意为成长付出溢价
   C. 困境反转 - 投资困境公司,等待重组或反转
   D. 红利投资 - 关注稳定分红和现金流
```

**如何选择**:
- 如果你喜欢巴菲特风格 → 选 **A. 价值投资**
- 如果你看好科技股、AI等新兴行业 → 选 **B. 成长投资**
- 如果你关注高股息率股票 → 选 **D. 红利投资**

#### 问题2: 持有周期

```
**2. 您的持有周期?**
   A. 短期 (<6个月)
   B. 中期 (6-18个月)
   C. 长期 (1-3年以上)
```

**如何选择**:
- 长期投资者 → 选 **C. 长期**
- 这会影响研究深度:长期会更关注护城河、可持续性

#### 问题3: 研究重点

```
**3. 您最关心哪些方面? (选2-3个)**
   - 生意质量: 护城河、定价权、商业模式
   - 财务质量: 现金流、盈利质量
   - 行业态势: 行业周期、竞争格局
   - 公司治理: 管理层、资本配置
   - 估值: 是否便宜、安全边际
   - 催化剂: 近期催化因素
```

**如何选择**:
- 价值投资者建议选: **生意质量 + 估值 + 公司治理**
- 成长投资者建议选: **生意质量 + 行业态势 + 催化剂**

#### 问题4: 风险偏好

```
**4. 您的风险偏好?**
   - 保守: 避免高负债、风险资产
   - 平衡: 可接受适度风险
   - 激进: 可承受高波动
```

**如何选择**:
- 如果你担心本金损失 → 选 **保守**
- 如果你能承受股价波动30% → 选 **平衡**
- 如果你是年轻投资者,追求高收益 → 选 **激进**

---

### 3.3 第3步: 生成结构化研究指令

系统会根据你的回答,生成一份**定制化的研究计划**。

**示例(价值投资者)**:

```markdown
### Investment Research Target
**Stock Ticker**: 600519.SH
**Company Name**: 贵州茅台酒股份有限公司
**Market**: A-share

### Investment Parameters
**Investment Style**: Value Investing (深度价值)
- Focus: 护城河、安全边际、内在价值
- Implications: 重点关注护城河评级、DCF估值、财务质量

**Holding Period**: Long-term (3+ years)
- Research implications: 强调护城河持久性、长期竞争力

**Risk Tolerance**: Conservative
- Constraints: 避免高负债公司,要求强现金流

### Research Scope
**Deep Dive Priority**:
- Priority 1: 生意质量 & 护城河
- Priority 2: 估值 & 安全边际
- Priority 3: 公司治理

**Valuation Methods Required**:
- DCF估值(保守假设)
- 历史估值分位数(5-10年)
- 同行对比
- 反向DCF(当前价格隐含的增长率)
```

### 3.4 第4步: 执行8阶段研究(核心!)

**这是整个流程最核心的部分**。

系统会**并行部署约28个研究智能体**,每个智能体负责一个细分任务。

#### 8阶段详解

**Phase 1: 公司事实底座** (4个智能体并行)

| Agent | 任务 | 时间 |
|-------|------|------|
| Agent 1A | 研究核心产品和业务模式 | ~5分钟 |
| Agent 1B | 研究收入和利润构成 | ~5分钟 |
| Agent 1C | 研究客户和价值链位置 | ~5分钟 |
| Agent 1D | 研究近期战略变化 | ~5分钟 |

**Agent实际做什么**:
```
Agent 1A 的工作流程:
1. 使用 WebSearch 搜索"贵州茅台 产品 业务模式"
2. 使用 WebFetch 访问公司官网、年报
3. 使用 Read 阅读已有研究文件
4. 整理发现,写摘要报告
5. 返回给主控智能体
```

**Phase 2: 行业周期分析** (4个智能体)

- Agent 2A: 判断行业周期阶段(扩张/收缩/复苏)
- Agent 2B: 分析供需动态
- Agent 2C: 竞争格局和市场集中度
- Agent 2D: 政策和外部因素

**Phase 3: 业务拆解** (4个智能体)

- Agent 3A: 各业务分部深度分析
- Agent 3B: 利润引擎和经济性
- Agent 3C: 客户和定价分析
- Agent 3D: 子公司和非核心资产

**Phase 4: 财务质量** (4个智能体)

- Agent 4A: 关键指标趋势(5-10年)
- Agent 4B: 现金流质量(OCF/NI, FCF/NI)
- Agent 4C: 异常筛查(应收账款、存货、一次性项目)
- Agent 4D: 同行对比

**Phase 5: 股权治理** (4个智能体)

- Agent 5A: 股权结构
- Agent 5B: 管理层质量和激励
- Agent 5C: 资本配置历史记录
- Agent 5D: 股东回报和股权稀释

**Phase 6: 市场分歧** (4个智能体)

- Agent 6A: 多头观点研究
- Agent 6B: 空头观点研究
- Agent 6C: 关键争议点
- Agent 6D: 验证节点(什么数据能解决争议)

**Phase 7: 估值护城河** (4个智能体)

- Agent 7A: 护城河评级(0-5分)
- Agent 7B: 相对估值(PE, PB, PS)
- Agent 7C: 绝对估值(DCF, 反向DCF)
- Agent 7D: 风险情景分析

**Phase 8: 综合报告**

- 汇总所有阶段发现
- 生成信号灯评级(🟢/🟡/🔴)
- 创建监控清单
- 编写参考文献

## 4. Agent调用机制

### 4.1 什么是Agent?

**Agent** = **智能研究助手**

每个Agent就像一个专门的分析师,负责研究某个具体方面。

**类比理解**:
- 主智能体 = 项目经理(协调全局)
- Agent 1A = 产品分析师(研究产品)
- Agent 4B = 财务分析师(研究现金流)
- Agent 7A = 估值分析师(研究护城河)

### 4.2 并行部署原理

**核心概念**: **28个Agent同时工作,而不是一个个排队**

#### 传统方式(串行) ❌

```
Agent 1A 完成 (5分钟) → Agent 1B 开始 → Agent 1B 完成 (5分钟) → ...
总时间 = 5分钟 × 28 = 140分钟 (2.3小时)
```

#### 本系统方式(并行) ✅

```
同时启动:
Agent 1A (5分钟) ┐
Agent 1B (5分钟) ├─→ Phase 1 完成 (5分钟)
Agent 1C (5分钟) │
Agent 1D (5分钟) ┘

Agent 2A (5分钟) ┐
Agent 2B (5分钟) ├─→ Phase 2 完成 (5分钟)
Agent 2C (5分钟) │
Agent 2D (5分钟) ┘

...

总时间 = 5分钟 × 7阶段 = 35分钟 (研究部分)
         + 汇总时间 = ~15分钟
         + 验证时间 = ~10分钟
         总计 ≈ 60-90分钟
```

**效率提升**: 2-3倍!

### 4.3 Agent如何协作?

#### 单个Phase的协作流程

**示例: Phase 1 (公司事实底座)**

```
┌─────────────────────────────────────────────────┐
│  主智能体启动Phase 1                              │
│  (在同一消息中调用4个Task工具)                     │
└─────────────────────────────────────────────────┘
        ↓
┌──────────┬──────────┬──────────┬──────────┐
│ Agent 1A │ Agent 1B │ Agent 1C │ Agent 1D │  ← 4个并行
│(产品)    │(收入)    │(客户)    │(战略)    │
└──────────┴──────────┴──────────┴──────────┘
        ↓           ↓           ↓           ↓
    [报告1A]    [报告1B]    [报告1C]    [报告1D]
        ↓           ↓           ↓           ↓
┌─────────────────────────────────────────────────┐
│  主智能体收集所有报告                              │
│  - 编译发现                                        │
│  - 识别矛盾                                        │
│  - 创建Phase 1综合报告                             │
└─────────────────────────────────────────────────┘
        ↓
    [01_Business_Foundation.md]
```

#### Agent交叉验证

**Agent 1C 的发现**: "茅台95%收入来自批发渠道"

**Agent 1D 的发现**: "i茅台直销占比从5%增长到45%"

**矛盾检测**: 主智能体发现数据矛盾

**解决方案**:
1. 检查时间差异(Agent 1C的数据可能较旧)
2. 验证来源(Agent 1D引用的是2023年报)
3. 更正结论: "2020年批发95%,2023年直销45%"

## 5. 工具使用说明

### 5.1 Agent使用的核心工具

每个研究Agent会使用以下工具:

| 工具名称 | 作用 | 使用场景 |
|---------|------|---------|
| **WebSearch** | 网络搜索 | 搜索公司信息、新闻、研报 |

## 8. 常见问题解答

### Q1: `/stock-research` 能预测股价吗?

**❌ 不能**

本系统**不预测股价、不给投资建议、不推荐买入卖出**。

系统只基于基本面分析,提供:
- ✅ 护城河评级
- ✅ 财务质量评估
- ✅ 估值分析(是否合理偏高/偏低)
- ✅ 风险分析

**信号灯评级**是基于基本面,不是股价预测:
- 🟢🟢🟢 = 基本面强+估值有安全边际
- 🟡🟡🟡 = 基本面强但估值合理偏高
- 🔴🔴 = 基本面恶化或估值明显过高

- 深度研究(优先领域深挖): ~120-180分钟

- 网络搜索额度(每天有上限)

✅ **引用验证**: citation-validator检查引用完整性

**局限性**:
- ⚠️ 依赖公开信息(无法获取内部数据)
- ⚠️ 网络搜索有上限(可能错过部分数据)

### Q6: Agent会出错吗?

**可能的问题**:

❌ **引用缺失**: 某个数据忘记写引用来源

❌ **数据矛盾**: 不同Agent数据不一致

❌ **来源错误**: 使用低质量来源(D/E级)

❌ **理解偏差**: Agent误解数据含义

**质量保障措施**:

✅ **citation-validator**: 强制检查引用完整性

✅ **交叉验证**: 多Agent独立验证同一数据

✅ **来源评级**: 明确标注来源质量(A-E)

✅ **矛盾标注**: 发现矛盾会明确说明

**用户如何检查**:

1. 查看 `sources/bibliography.md`,检查来源质量
2. 重点验证A级来源(年报数据)
3. 对可疑数据,通过官方渠道核实

## 📚 附录: 关键术语解释

### A-E来源评级

| 评级 | 含义 | 示例 | 可信度 |
|------|------|------|--------|
| **A级** | 最权威 | 年报、监管文件、学术论文 | ⭐⭐⭐⭐⭐ |
| **B级** | 高质量 | 券商研报、行业报告 | ⭐⭐⭐⭐ |
| **C级** | 中等质量 | 新闻、专家观点 | ⭐⭐⭐ |
| **D级** | 较低质量 | 博客、预印本 | ⭐⭐ |
| **E级** | 最低质量 | 社交媒体、论坛 | ⭐ |

---

### 护城河评级(0-5分)

| 评分 | 含义 | 典型公司 |
|------|------|---------|
| **5分** | 极强护城河,10年+可持续 | 茅台、可口可乐 |
| **4分** | 强护城河,5-10年可持续 | 苹果、腾讯 |
| **3分** | 中等护城河,3-5年可持续 | 美团、小米 |
| **2分** | 较弱护城河,1-3年可持续 | 多数科技公司 |
| **1分** | 极弱护城河,易被颠覆 | 初创公司 |
| **0分** | 无护城河 | 纯竞争市场 |

---

### 关键财务指标

| 指标 | 含义 | 优秀标准 |
|------|------|---------|
| **ROE** | 净资产收益率 | >15%优秀 |
| **毛利率** | 销售毛利/收入 | >50%优秀 |
| **净利率** | 净利润/收入 | >20%优秀 |
| **OCF/NI** | 经营现金流/净利润 | >1.0优秀 |
| **FCF/NI** | 自由现金流/净利润 | >0.8优秀 |
| **P/E** | 股价/每股收益 | 需结合增长判断 |
| **P/B** | 股价/每股净资产 | <3合理 |

---

### 估值方法

| 方法 | 适用场景 | 局限性 |
|------|---------|-------|
| **DCF** | 长期价值投资 | 需假设增长率,敏感性强 |
| **相对估值(PE/PB)** | 快速判断 | 需同行对比,历史对比 |
| **反向DCF** | 检验当前价格 | 只能判断隐含假设 |
| **DDM** | 红利投资 | 不适合不分红股票 |
